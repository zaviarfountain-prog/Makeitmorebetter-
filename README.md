# Sky's the Limit — Alpha 1.0

Playable React Native + Expo alpha.

Flow:
Character creation → dream → housing → transportation → work → bill → payday → $399 temptation → Week 1 report → free-roam city map.

This source package is intentionally small so it can be uploaded to GitHub and built with Expo/EAS.

## Important
The Expo website project is already connected to the GitHub repository. After these files are committed to the repository, Expo/EAS can detect the app source.

If Expo asks to link the source app to an existing EAS project, use the existing Makeitmorebetter project rather than creating another one.
